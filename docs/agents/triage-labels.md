# Rótulos de triagem

As skills falam em cinco papéis de triagem. Esta tabela liga cada papel ao rótulo usado nas Issues deste repositório.

| Papel nas skills    | Rótulo no GitHub    | Significa                                  |
| ------------------- | ------------------- | ------------------------------------------ |
| `needs-triage`      | `needs-triage`      | Chegou e ninguém avaliou ainda             |
| `needs-info`        | `needs-info`        | Falta informação de quem abriu             |
| `ready-for-agent`   | `ready-for-agent`   | Especificado por completo, pronto para um agente |
| `ready-for-human`   | `ready-for-human`   | Precisa de uma pessoa para implementar     |
| `wontfix`           | `wontfix`           | Não vai ser feito                          |

Quando uma skill citar um papel (por exemplo, "aplique o rótulo de pronto para agente"), use o rótulo correspondente desta tabela.

Os tickets do `/to-tickets` já saem com `ready-for-agent` e não passam pela triagem.

Se um dia os rótulos do GitHub mudarem de nome, edite a coluna "Rótulo no GitHub".
